Microsoft Visual C++ Runtime Libraries

Microsoft.Windows.WinmdGenerator includes app-local x64 Visual C++ runtime
libraries from Visual Studio's Microsoft.VC*.CRT redistributable directory.

https://visualstudio.microsoft.com/license-terms/
https://learn.microsoft.com/cpp/windows/redistributing-visual-cpp-files

Package maintainers must keep the bundled runtime libraries updated for
security and compatibility; Windows Update does not service these app-local
copies.
